# Arena Clicker

نسخه ویندوزی Arena Clicker برای Auto Click و Double/Triple Click.

## دانلود
[دانلود سورس و فایل‌های ساخت (ZIP)](ArenaClicker-Phoenix-1.8.9.zip)

## تغییرات نسخه Phoenix / Minecraft 1.8.9
- Double و Triple هنگام فشردن دکمه اجرا می‌شوند، نه هنگام رها کردن آن.
- مکث مصنوعی و صف worker برای Double/Triple حذف شده است.
- چپ و راست مستقل هستند.
- Auto Click دست‌نخورده باقی مانده است.

## اجرا
ZIP را استخراج کن و `run.bat` را اجرا کن. برای ساخت EXE، `build.bat` را اجرا کن.

> سازگاری با Phoenix Client تضمین‌شده نیست؛ بعضی کلاینت‌ها یا تنظیمات بازی ورودی مصنوعی ویندوز را فیلتر می‌کنند. کد از نظر syntax بررسی شده، اما روی خود Minecraft/Phoenix runtime-test نشده است.
